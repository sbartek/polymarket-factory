# Strategy Ideas

This directory is for strategy concepts that are worth keeping, but not worth implementing yet.

Use `ideas/` when the concept is:
- plausible
- incomplete
- blocked on missing data or infrastructure
- overlapping with a better near-term strategy
- intentionally parked for later

Do not use `ideas/` for:
- strategies already being built or benchmarked
- concrete implementation proposals ready for review
- experiment results or postmortems

Lifecycle:
- `ideas/` -> rough backlog for later
- `proposals/` -> concrete candidate ready for design review
- `factory/strategies/` -> implemented strategy in the codebase

Suggested filename format:
- `ID-YYYYMMDD-xxx-short_slug.md`

Suggested statuses:
- `backlog`
- `blocked`
- `parked`
- `merged_into_other_idea`
- `promoted_to_proposal`
